# Advanced Driver Assistance System (ADAS) with Real-Time Interactive Display

An intelligent **Advanced Driver Assistance System (ADAS)** designed to enhance driver safety through computer vision, sensor fusion, and real-time interaction[cite: 3]. This system integrates lane departure warnings, traffic sign and signal detection, collision avoidance, and a dedicated real-time interactive display dashboard[cite: 3].

---

## 📌 Features

* 🛣️ **Lane Keep Assist:** Detects lane markings to provide lane discipline and departure warnings[cite: 3].
* 🚦 **Traffic Sign & Signal Detection:** Real-time recognition of speed limits, traffic signs, and signal states[cite: 3].
* 🛡️ **Collision Avoidance:** Uses LiDAR technology for precise distance measurement and immediate obstacle detection[cite: 3].
* 🖥️ **Interactive Display Dashboard:** Displays critical alerts, traffic signs, and vehicle states directly to the driver via an LCD screen[cite: 3].

---

## 🛠️ Hardware & Software Architecture

### Hardware Components
* **Raspberry Pi 4 Model B:** Primary processing unit handling computer vision algorithms and machine learning models[cite: 3].
* **Arduino Mega:** Controls low-level hardware operations, including motor controllers and sensor readings[cite: 3].
* **GYUL530XU2 LiDAR Sensor:** Precise distance measurement for dynamic collision avoidance[cite: 3].
* **LCD Display:** Real-time driver dashboard interface[cite: 3].
* **L298N Motor Driver:** Drives and steers the vehicle chassis[cite: 3].
* **Peripherals:** Camera Module, HC-05 Bluetooth Module, XL6019 Voltage Regulator, Vehicle Chassis, Power Supply[cite: 3].

### Software Stack
* **Languages & Frameworks:** Python, C/C++, OpenCV, TensorFlow Lite[cite: 3]
* **Development Environments:** Arduino IDE, Thonny IDE, Google Colab[cite: 3]
* **Operating Systems & Connectivity:** Raspberry Pi OS, Android Studio (App UI), Bluetooth Connectivity[cite: 3]
